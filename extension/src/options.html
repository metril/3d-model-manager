Save to my library — settings

Connect the extension to your self-hosted app.

The base URL of your app, no trailing path. Use https unless it is on your local network.

Warning: this address is plain http on a non-local host, so your API token would be sent unencrypted.

Create one in the app under Settings → Accounts → Browser extension.

Send to printer (optional)

A separate app API key with the queue and read scopes. It adds a printer picker and “Add to queue” to the popup and a “Save & queue” right-click entry. Leave empty to turn this off.
