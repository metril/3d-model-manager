# Q8b: printer sensor history + stats API extensions

Backend only (the `/stats` widget page + history modals are Q8c/Q3 web work).
Spec: Bambuddy parity v2, Q8 (stats + sensor history), risk decision 6.

## Sensor history
- Table `printer_sensor_samples(id, printer_id, ts, nozzle, nozzle_target, bed,
  bed_target, chamber, fan_part, ams JSONB, created_by_user_id)`, index
  `(printer_id, ts)`; migration `b8c3d5e7a1f2` chained from `a8e2d4c6b1f3`.
- No extra polling: printerd already keeps the last `PrinterPublicState` per
  worker. `PrinterWorker.sensor_tick()` runs in the existing 2.5 s poll loop;
  at most every 60 s it hands a snapshot to a throwaway daemon thread that
  calls `sensors.record.apply_async` (never DB from printerd/MQTT; a dead broker
  can't stall the loop). Skips when the printer never reported or
  `last_report_at` has not advanced (offline/stale).
- `app.tasks.sensors.record` inserts the row; `prune` (beat, daily 03:15 UTC)
  deletes rows older than `AppConfig.sensor_history_days` (default 30, exposed
  on `PUT/GET /settings/app`).
- Routes (`require_printer_access("print")`): `GET /printers/{id}/sensors?from&to&step`
  (SQL-bucketed averages, step raised so <= 500 points; default window 24 h) and
  `GET /printers/{id}/ams-history?unit&from&to` (last AMS snapshot per bucket).

## Stats widgets
- `services/stats_widgets.py`: ONE joined query (archive + job + printer +
  print) over the `days` window, visibility-filtered via `visible_printer_ids`,
  folded in Python into: success rate, time accuracy (est = slicer
  `print_time_s` vs `duration_s`, completed only; delta histogram + points),
  failure analysis (error code / HMS / printer / material), weekday x hour
  heatmap (UTC), records, per-printer stats. Filament trends = one grouped
  `spool_usage` query (grams per week x material).
- `GET /stats/dashboard?days=` returns all widgets (2 queries total) plus
  `/stats/{success-rate,time-accuracy,failures,heatmap,records,printers,filament-trends}`.

## Tests
`test_migrations_q8b.py`, `test_sensor_history.py` (record/prune/downsample/ACL),
`test_stats_api.py` (every widget seeded, empty/window, visibility),
`test_printerd.py` (timer enqueues once/interval, skips stale, never blocks).

covered by `test_auth_sweep` + the explicit ACL tests.
