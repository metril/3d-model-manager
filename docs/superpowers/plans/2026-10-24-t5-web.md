# T5-web: spool housekeeping (frontend)

Spec: bambuddy parity v3 design, "T5 Spool housekeeping". Backend (T5-be) built in parallel; web mocks this contract.

## API contract (all under `/api`)
- Suppliers `GET/POST /suppliers`, `PATCH/DELETE /suppliers/{id}` -> `{id, name, website, customer_number, note, created_at}`.
- Locations `GET/POST /storage-locations`, `PATCH/DELETE /storage-locations/{id}` -> `{id, name, identifier, created_at, sensors?: Sensor[]}`.
  Sensors `GET/POST /storage-locations/{id}/sensors`, `PATCH/DELETE /storage-locations/sensors/{sid}`, `GET /storage-locations/sensors/entities` -> `[{entity_id, name, device_class, unit, state}]`, `GET /storage-locations/{id}/readings` -> `[{sensor_id, state, unit, alerting, last_changed_at}]`.
  Sensor = `{id, location_id, name, entity_id, kind, device_class, unit, alert_above, alert_below, notify_on_alert, show_on_card, sort_order, last_state, last_changed_at, alerting}`.
- Colour catalog `GET/POST /color-catalog`, `PATCH/DELETE /color-catalog/{id}`, `GET /color-catalog/search?q=`, `GET /color-catalog/lookup?manufacturer=&name=`, `GET /color-catalog/by-material/{material}`, `POST /color-catalog/reset` -> `{id, manufacturer, color_name, hex, material, is_default, extra_colors: string[], effect_type}`.
- Spool gains `location_id`, read-only `location` (name), `suppliers: [{supplier_id, article_number, quoted_price_per_kg, is_purchase_source}]`; `PUT /spools/{id}/suppliers` (same list).
- Bulk `POST /spools/bulk-update {ids, update}` -> `{results:[{id, ok, error?}], not_found:[]}`; `POST /spools/bulk-delete|bulk-archive|bulk-restore {ids}`.
- CSV `GET /spools/export.csv`; `POST /spools/import?dry_run=true` multipart `file` -> `{token, rows:[{line, action: create|update|error, spool_id?, errors[], warnings[]}], summary:{create, update, error}}`; `POST /spools/import/commit {token}` -> `{created, updated, errors}` (410 = expired token).
- Labels `POST /spools/labels {ids, template: tight|roomy, page: a4|letter|roll_62mm, format: pdf|png}` -> binary; `POST /spools/labels/preview {ids, template, page}` -> image/png.

## Assumptions beyond the contract
- Bulk-delete/archive/restore responses are not inspected beyond success (any JSON/204).
- `SpoolCreate`/`SpoolUpdate` accept `location_id` (the free-text `location` is no longer sent).
- Preview/labels use `fetch` with `credentials: include` (binary), not the JSON client.
- Import multipart field name is `file`.

## Components
- `api/spoolAdmin.ts` hooks; `downloadBlob`.
- `components/inventory/`: `SpoolTable` (selection, toolbar, location filter), `BulkEditDialog`, `CsvImportDialog`, `LabelsDialog`, `SpoolForm` (location combobox, `SupplierListEditor`, `ColorCatalogPicker`).
- `components/inventory/admin/`: `SuppliersPanel`, `LocationsPanel` (+ sensors), `ColorCatalogPanel`.
- `pages/SpoolsPage`: `?tab=spools|suppliers|locations|colors` strip.
