# T4-be: queue scheduling + batches (API contract)

Branch `t4-be-queue-scheduling` (stacked on `t3-be-printer-ops`). Migration chains off `d3a7c1e5f9b2`.

## Queue entry fields (request + response)
`QueueEnqueueIn` (POST /queue) and `PATCH /queue/{id}` accept: `scheduled_at` (ISO datetime|null), `manual_start` bool, `require_previous_success` bool, `auto_off_after` bool, `preheat_override` ("on"|"off"|null), `preheat_chamber_target` (int 0-65|null), `batch_id` (int|null; enqueue only).
`QueueEntryOut` adds those plus `released_at`, `stage` ("preheating"|"soaking"|null), `skipped_reason` (hold_reason when state=skipped), `waiting_reason` ("scheduled"|"manual"|"plate"|<hold_reason>|null), `batch` ({id,name}|null).
`QueueState` gains `skipped`.

## Routes (perm)
- `PATCH /queue/{id}` (`printers:print`, owner/admin) body `{position?, scheduled_at?, manual_start?, require_previous_success?, auto_off_after?, preheat_override?, preheat_chamber_target?}` (only sent keys applied; `null` clears) -> full ordered queue list.
- `POST /queue/{id}/start` (`queue:review`) -> QueueEntryOut (sets released_at/by).
- `POST /queue/{id}/cancel-schedule` (`printers:print`, owner/admin) -> QueueEntryOut (scheduled_at=null).
- `POST /printers/{id}/queue/resume` (`queue:review`) -> `{resumed: n}` ; SKIPPED -> WAITING, hold_reason cleared, those entries stop requiring previous success (acknowledged). AuditLog.
- `GET /queue?batch_id=` filter.
- `GET/PUT /settings/queue-preheat` (PUT `settings:write`): `{enabled, chamber_targets{filament:C}, bed_targets{filament:C}, max_wait_s 60-3600, soak_s 0-1800, keep_warm_enabled, keep_warm_bed_c 40-110, keep_warm_max_min 5-480}`.
- Batches (`queue:review`): `GET /batches`, `POST /batches`, `GET/PATCH/DELETE /batches/{id}`, `POST /batches/{id}/dispatch`, `POST /batches/{id}/ungroup`.
  - POST body: `{name, model_id?|file_id?, recipe_id?, printer_id?, quantity 1-500, due_date?, notes?, plate_targets? {plate:qty}, cost_center_id?, scheduled_at?, manual_start?, require_previous_success?, auto_off_after?, preheat_override?, preheat_chamber_target?}`.
  - POST also accepts `ams_mapping` (int[]|null), `options` ({bed_levelling,flow_cali,timelapse}|null), `copies_per_entry` (1-50, default 1); dispatch applies them to every generated entry (`copies=copies_per_entry`).
  - `BatchOut` additionally: `model_name`, `file_name`, `ams_mapping`, `options`, `copies_per_entry`.
  - `BatchOut`: `{id,name,model_id,file_id,recipe_id,printer_id,quantity,status draft|active|done|cancelled,due_date,notes,plate_targets,cost_center_id,created_by_user_id,created_at,progress{total,done,failed,skipped,waiting}}`.
  - dispatch -> `BatchOut` (409 if not draft); DELETE -> 204: first call removes non-dispatched entries and sets status `cancelled` (row kept); a second DELETE on a cancelled batch removes the row.
- New notify event `queue_item_skipped`.
