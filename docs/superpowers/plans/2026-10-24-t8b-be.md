# T8b-be: G-code extraction endpoints + toolpath tab

Contract (all session-authenticated, streamed, gzip when `Accept-Encoding: gzip`, `text/plain; charset=utf-8`):
- `GET /api/archives/{id}/gcode?plate=N` - `Metadata/plate_N.gcode` from the archived 3MF; default plate = archive.plate or job.plate or 1; 404 when blob/member absent; same visibility as `/archives/{id}/file`.
- `GET /api/archives/{id}/gcode/plates` -> `[{plate, bytes}]`.
- `GET /api/printers/{id}/files/gcode?path=&plate=` - `printers:control` access; path absolute, no `..`, `.3mf`/`.gcode.3mf`/`.gcode` only (422 otherwise); downloads via `adapter.download_file` to a temp dir (cleaned by background task), default plate = lowest present; plain `.gcode` streams directly; 404 missing file/plate, 502 on download failure.
- Zip members are streamed in 256 KiB chunks; nothing is loaded whole.
