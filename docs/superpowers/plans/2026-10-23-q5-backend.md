# Q5-backend: HMS catalog, firmware, diagnostics, discovery

Backend only; modals/UI land in Q5-web. No new tables.

## HMS
- `backend/app/data/hms_{catalog,catalog_extra,actions}.json` copied from the
  author's earlier bambuddy project (`.gitignore` un-ignores `backend/app/data/`).
- `services/hms.py`: `decode_hms/decode_print_error/decode_state` -> code
  (`0300_0100_0001_0001`), severity, module, description, wiki URL, remedy actions.
  Unknown code -> raw code + wiki link, never raises; `code < 0x4000` ignored.
- `GET /printers/{id}/hms` (print). `POST .../hms/clear` and `.../hms/action`
  (control) publish `hms_clear` / `hms_action`(+`args`) through `_publish_command`
  (new optional `args`); printerd `handle_command(command, args=None)` calls adapter
  `clear_hms()` / `execute_hms_action()`. `PrinterAdapter` defaults raise
  `NotImplementedError`; Bambu impl uses `_publish_raw` (`hms_action_payload`).

## Firmware
- `services/firmware.py`: wiki release-history anchors (version source) + bambulab.com
  Next.js JSON (image URL, notes; optional, Cloudflare may block). Cached in
  `settings` row `firmware_latest`, refreshed by daily beat `check_firmware`.
- `GET /printers/{id}/firmware`: current (`firmware.ota`), latest, notes,
  `update_available`, last upload status.
- `POST .../firmware/upload` (`settings:write` + control): 409 unless an update with an
  image exists; Celery `upload_firmware` downloads and FTPS-stages to the SD root
  (`PrinterAdapter.upload_file`). Never flashes. Log line records actor (audit table is Q2).

## Diagnostics
- `probe.diagnose()` -> `{ok, checks[{id,status ok|fail|skip,hint,detail}]}`: TCP
  8883/990/6000/322 (camera port not used by the model = skip), TLS serial, MQTT auth
  (`ProbeResult.stage`), dev mode (Redis state or skip), container network mode, subnet.
- `POST /printers/diagnostic` (ad hoc), `GET /printers/{id}/diagnostic` (`settings:write`).

## Discovery
- `discovery.parse_ssdp / ssdp_listen` (UDP 2021) + `sweep` (bounded thread pool,
  TCP 8883 + TLS cert CN) + `discover` (merge; SSDP wins). `POST /printers/discover`
  (`settings:write`, optional `cidr`, 10 s budget).
