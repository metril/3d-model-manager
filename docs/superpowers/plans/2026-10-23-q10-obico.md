# Q10 Obico failure detection (plan)

Spec: `docs/superpowers/specs/2026-10-23-bambuddy-parity-v2-design.md` (Q10, risk 6).

## Decisions
- Obico's ML API is GET-only (`/p/?img=<url>`), so the watcher stashes the JPEG in Redis under a
  one-shot nonce; the API serves it at public `GET /api/obico/frame/{nonce}` (unguessable, GETDEL,
  30 s TTL). `callback` (env `TDMM_OBICO_CALLBACK`, default `http://api:8000`) is what the sidecar fetches.
- Config in `settings` rows (no printers-table change): `obico` (global) and `obico_printer:{id}`.
- Event frame JPEG kept in Redis (`obico:evt:{id}`, 7 d); `failure_detections.frame_blob_key` holds the key.
- Auto-disable (3 consecutive ML errors) lasts until the job ends / printerd restarts.
