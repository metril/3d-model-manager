# T1-web: AMS drying (frontend)

Stacked on `t3-web-printer-ops`. Contract = `2026-10-24-t1-be.md` (T1-be branch).

## Components
- `api/drying.ts`: `useStartDrying/useStopDrying(printerId)` (`POST /printers/{id}/drying/start|stop`), `useDryingSchedules(printerId)`, `useCreateSchedule(printerId)`, `useCancelSchedule` (`DELETE /drying/schedules/{sid}`), `useDryingPresets` (`GET /drying/presets`), `useDryingSettings/useUpdateDryingSettings` (`/settings/drying`). Errors: 409 `screen_only|blocked|printing`, 422 `unsupported` -> toast.
- `modals/DryingDialog.tsx` (kind `drying`, `sm:max-w-lg`, opened with unit id): filament + presets (n3f ids 0-3 / n3s ids >=128), clamped temp 45-85 / hours 1-24, rotate switch, start mode Now | At time | After current print, blocked-reason panel (`dry_sf_reason`), Stop when active, embedded schedules list.
- "After current print" = `POST .../drying/schedules` without `start_after` (tick waits with `printer_busy`).
- `card/DryChip.tsx` in `UnitHeader`: status + sub-status, client countdown from `dry_time_min`, target temp + filament, Stop (control). Screen-only: chip + tooltip, no Dry button.
- `usePrinterModals.open(kind, arg?)` carries the unit id; `PrinterCard` gets `onDry`.
- Settings -> Printer: `DryingSettingsCard`, `ScheduledDryingsList` (also compact in the dialog).
