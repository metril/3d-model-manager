# T3-web: printer ops frontend

Codes against `2026-10-24-t3-be.md` (T3-be). Mocked-API vitest.

## Contract used
- `POST /printers/{id}/clear-plate`; `PrinterStatus.awaiting_plate_clear`.
- `POST /printers/{id}/control/xcam {module, enable, sensitivity}`; `.../control/print-option {option, value}`; `status.print_options {xcam:{m:{enable,sensitivity}}, auto_recovery, auto_switch_filament}`; caps `xcam_modules`, `sd_browser`, `sd_print`.
- `POST /printers/{id}/slots/{unit}/{slot}` (`tray_info_idx, tray_type, sub_brand, color RRGGBB, nozzle_min, nozzle_max, apply_device`); `DELETE .../slots/{unit}/{slot}/device`.
- `PUT|DELETE /printers/{id}/ams/{ams_id}/label`; `ams_units[].label`.
- SD: `GET /files?path=`, `GET /files/download?path=`, `DELETE /files?path=`, `GET /files/storage`, `POST /files/print {path, use_ams}`.
- Assumed (not in be doc): list returns array (or `{entries|files}`) of `{name, path?, size, mtime, is_dir}`; storage `{total, used, free}` bytes.

## Components
- `api/printerOps.ts`: `useClearPlate`, `useConfigureSlot`, `useResetSlotDevice`, `useAmsLabel`, `usePrinterFiles`, `useFileStorage`, `fileDownloadUrl`, `useDeletePrinterFile`, `usePrintSdFile`; `ControlPath` += `xcam`, `print-option`.
- `StatusSection` plate pill + "Mark plate cleared".
- `modals/PrintOptionsModal` (kind `printOptions`), `modals/FileManagerModal` (kind `files`, `previewSlot` prop).
- `card/SlotConfigDialog`, `card/AmsRenameDialog`; `FilamentsSection` menus.
- `usePrinterCardExtras` footer: Print options (control), Files (`caps.sd_browser`).
