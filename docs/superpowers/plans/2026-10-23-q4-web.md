# Q4-web: camera viewer, window, overlay, camwall

Spec: `docs/superpowers/specs/2026-10-23-bambuddy-parity-v2-design.md` (Q4, risk 5). Depends on backend PR #21.

## API contract (mocked in tests)
- `GET /printers/{id}/camera/status` -> `{status, source: a1|rtsp|external|none, beta, rotation, default_fps}`
- stream `/api/printers/{id}/camera/stream?token=&fps=1..15`; snapshot `.../camera/snapshot?token=`
- `POST /printers/{id}/camera/token` (existing `useCameraUrls`)
- `POST|GET /printers/{id}/overlay-tokens`, `DELETE .../{token_id}` (control); create returns `token`, `overlay_url` once
- public `GET /api/overlay/{id}?token=` -> name/state/progress/layer/total_layers/remaining_min/temps/rotation/stream_url/snapshot_url
- light: `POST /printers/{id}/control/light {on}` (Q2), rendered only for `canPrinter(id,"control")`

## Tasks
1. `api/printers.ts` + `types.ts`: `useCameraStatus`, overlay-token hooks, types.
2. `hooks/useElementFullscreen.ts` (Fullscreen API hook).
3. `CameraTile.tsx` rewrite, props API kept (`printerId, online, className`) plus optional `snapshotOnly`, `snapshotSec`, `urls`, `rotation`, `controls`. Zoom (wheel/pinch), pan (drag), dbl-click reset; CSS rotation; fullscreen; light; stream/snapshot toggle; fps select; stall watchdog (5 s no new frame -> reconnect, backoff 1s..30s, 5 attempts); beta badge; unmount drops img src (no backend stop route exists).
4. `CameraSplitButton.tsx` + `openCameraWindow(id)` (for Q3).
5. Routes outside shell: `/camera/$id` (session), `/overlay/$id?token=` (no auth, transparent, 5 s poll via raw fetch), `/camwall` (session, kiosk; localStorage `camWallMaxLive`, `camWallSnapshotSec`; `selectLive` pure fn).
6. Settings: `PrinterCameraSection` (external kind/url, rotation -> `options.camera`, `options.rotation`) + `OverlayTokensList` inside `PrinterSetupCard`.
7. Tests: CameraTile, fullscreen hook, overlay page, camwall `selectLive`, settings section. Gate: `npm run build`, vitest, oxlint baseline 13.

## Deviations
- No long-lived `?token=` for camwall (backend only has per-printer overlay tokens): session auth.
- No camera stop route in backend: unmount drops img src.
