# Q3 plan: bambuddy-layout printer card + dashboard + Dev-Mode banner

Spec: `docs/superpowers/specs/2026-10-23-bambuddy-parity-v2-design.md` (Q3, risk 4). Web only.

## Sections (one commit + vitest each)
1. **API layer** - `types.ts` v2 fields (capabilities, targets, fans, light, speed, stage, hms, ams_units, ext_tray, dev_mode); `ApiError.code` (additive, from `{code,detail}` bodies); `api/printerControl.ts` (`useControl`, `sendControl`, skip-objects/objects hooks, dev-mode warnings hook); 409 `dev_mode_off|offline|cold_extrude|printing`, 422 `unsupported` -> toasts.
2. **card/ sections** (`web/src/components/print/card/`): `CardHeader`, `BadgeRow`, `StatusSection`, `TempFanTiles`, `ControlsSection`, `FilamentsSection`, `CardFooter`; shared `useCardSize`, `capabilities` helpers. Optimistic targets revert after 10 s; `verified===false` -> "untested on this model" tooltip.
3. **PrinterCard.tsx** composes the sections; slots `headerExtra`, `badgeExtra`, `footerExtra` (render props `(ctx)=>ReactNode`), `camera`, `badge`; callbacks `onInfo`, `onDiagnose` (Q5-web `usePrinterModals` drops in), Q7 `PlugRow`/`MaintenanceBadge` -> footer/badge slot, Q4 `CameraSplitButton` -> footer slot (TODO hooks, not imported).
4. **Sizes** S/M/L/XL: localStorage `printerCardSize`; grid 5/3/2/1; `--card-scale` 1/1/1.2/1.4; S = compact card, click expands to M + scroll + "Back" pill.
5. **Dashboard**: `StatusSummaryBar`, filters (status / hide-offline / search) + sort (name/status/model/ETA) with group headers, URL params (`printerDashSearch.ts`), bulk pause/stop toolbar, drop-file-on-card -> create model, upload, enqueue for that printer.
6. **DevModeBanner** in `AppShell` (60 s poll, session-dismissible, wiki link, grey "unknown" variant when an online printer has `dev_mode === null`).
7. **PrinterDetailPage** = XL card + large `CameraTile` + `PrintJobHistory` + `HistoryStats`.
8. Live-verify checklist `2026-10-23-q3-live-verify.md`.

## Decisions
- Skip-objects modal is a local `SkipObjectsDialog` in `card/` (checkbox list from `GET /objects`, `POST /skip-objects`).
- Print thumbnail: `/api/archives/{id}/thumbnail` from `last_runs[0]` for idle "Last:"; during a print no archive id is on the overview, so the 96 px slot shows the model glyph fallback (no backend change).
- Camera button: links to `/printers/$id` (camera lives there) until Q4-web merges.
- Control calls never retried; every 2xx treated as ok, 202 = "pending" toast-free.

## Tests
One vitest file per section (A1 Mini fixture: chamber/airduct/door/dual/aux absent; X1C fixture: present + untested tooltip), dashboard summary/filter/sort/bulk, banner, updated `PrinterCard`/`PrintDashboardPage`/`PrinterDetailPage` tests. Gate: `cd web && npm run build && npx vitest run <files>`; `npx oxlint --max-warnings=13`.
