# Q7-backend: maintenance, smart plugs, backups, updates, metrics

Spec: Bambuddy parity v2, Q7. Backend only; Q7-web consumes the contract below.
Migration `b7e1c4a9d3f2` (down `a8e2d4c6b1f3`): `printers.maintenance_mode`,
`maintenance_tasks`, `maintenance_logs`, `smart_plugs`, `backup_runs`.

## API contract (all under `/api`)
| Route | Perm |

| `GET /printers/{id}/maintenance` (tasks + due status) | session, visible printer |
| `POST /printers/{id}/maintenance`, `PATCH|DELETE .../{task_id}`, `POST .../{task_id}/done`, `PUT .../mode {enabled}` | `printers:control` on printer |
| `GET .../{task_id}/logs` | session, visible |
| `GET /printers/{id}/plug` (config secrets masked `***`) | session, visible |
| `POST /printers/{id}/plug/on|off` | `printers:control` |
| `PUT|DELETE /printers/{id}/plug` | `settings:write` (names hosts/URLs/credentials) |
| `GET|PUT /settings/ops` (backup schedule/retention, git target, update toggle; `git_token` write-only) | `settings:write` |
| `POST /admin/backups/run` (202), `GET /admin/backups`, `POST /admin/backups/{id}/restore-settings`, `GET /admin/support-bundle` | `admin` |
| `GET /system/update` `{latest,current,url,notes,update_available,checked_at,error}` | session |
| `GET /metrics` Prometheus text | `Authorization: Bearer <api token>`, owner must be admin |

`PrinterOut.maintenance_mode` added. Plug kinds/config: `tasmota {host,user?,password?}`,
`ha {entity_id,power_entity_id?}` (uses saved HA REST config), `mqtt {command_topic,on_payload,off_payload}`
(publish-only via saved HA MQTT broker), `rest {on_url,off_url,status_url?,state_path?,power_path?,method?,headers?,body?}`.

## Design
- Due status: hours since `last_done_hours` (archive print hours) and/or days since `last_done_at`;
  `soon` >= 90 %, `overdue` >= 100 %. Defaults seeded on `POST /printers` from capabilities
  (carbon rods x1/p1, lidar, chamber filter, AMS feeders).
- Dispatcher: maintenance-mode printers are excluded from busy/candidate selection; READY items wake
  `auto_on_before_print` plugs that are off (`_wake_plugs`).
- Plug beat `app.tasks.plugs.tick` (60 s): poll state/power; auto-off after `auto_off_after_min` of
  continuous idle (IDLE/FINISH/FAILED) with nozzle < 50 C (unknown nozzle = never off); power is
  integrated into `ha:energy:acc:{pid}` (same accumulator job start/finish snapshot -> `energy_kwh`
  x `energy_cost_per_kwh` in archive costing) unless the printer already has an HA `energy_kwh` link.
- Backups: `app.tasks.backup.run` writes `backups/<stamp>-<id>/db.dump` (`pg_dump -Fc`, password via
  `PGPASSWORD`) + `settings.json` through the active storage backend; optional git push of both
  (GitHub / Gitea / Forgejo / GitLab contents API, <= 50 MB per file); retention prunes old runs.
  `app.tasks.backup.scheduled` (10 min gate) starts a run when enabled and the last is older than the
  interval. Scanner skips `backups/`. Docker image gains `postgresql-client`.
- Updates: `app.tasks.updates.check` daily 04:17 -> settings row `update_cache`.
- Support bundle: redacted settings, versions, in-process log ring (API process only), zip.

## Manual DB restore (the app never auto-restores the DB)
1. Stop api/worker/beat/printerd. 2. Fetch `backups/<stamp>-<id>/db.dump` from the storage backend.
3. `pg_restore --clean --if-exists --no-owner -h HOST -U USER -d tdmm db.dump`
4. Start the stack (alembic upgrades to head). Settings-only recovery: `POST /admin/backups/{id}/restore-settings`.
