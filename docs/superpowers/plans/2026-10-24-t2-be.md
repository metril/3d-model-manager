# T2-be K-profiles (pressure advance) - API contract + tasks

Base: `t1-be-ams-drying`. Capability `kprofiles: bool` on `GET /printers/{id}/capabilities` (true for all Bambu models).

## Control routes (`/api/printers/{id}/...`, access `control`, printer must be enabled)
All commands use envelope v2; errors `{code, detail}`: 409 `offline|printing|dev_mode_off`, 422 `unsupported|invalid`, 504 `timeout`, 502 `error`.

- `GET kprofiles?nozzle=0.4&extruder=0&refresh=0&request_id=` -> 200 `{profiles, nozzle_diameter, fetched_at}`;
  fresh cache (<10 min) returned without a printer round trip unless `refresh=1`; otherwise a fresh `extrusion_cali_get`
  is issued and awaited <=3 s, else **202 `{status:"pending", request_id}`** - poll the same URL with `&request_id=` (202 until the result lands, then 200).
  `extruder` filters on dual-nozzle printers (omit = all). Allowed while printing and with Developer Mode off.
  Profile: `{cali_idx, setting_id, filament_id, name, k_value, n_coef, extruder_id, nozzle_id, nozzle_diameter, ams_id, tray_id, note}`
  (`k_value`/`n_coef` floats; `nozzle_diameter` per item, falling back to the response envelope; `note` from `kprofile_notes`).
- `POST kprofiles {name, filament_id, k_value, n_coef=0, nozzle_diameter="0.4", extruder_id=0, nozzle_id?, setting_id?, cali_idx?}` -> 200 `{ok, payload:{setting_id}}`.
  Create = omit `setting_id` (server mints `PF`+17 digits, `cali_idx=-1`); edit = send `setting_id` (+ `cali_idx`, else looked up from the cached list).
- `DELETE kprofiles/{setting_id}?nozzle=0.4&extruder=0&cali_idx=` -> 200 `{ok}`; `cali_idx`/`filament_id` resolved from the cached list when omitted (404 `kprofile_not_found` if unknown). Wire variant (X1 `setting_id` vs H2D `extruder_id`+`nozzle_id`) is chosen from `capabilities.dual_nozzle`.
- `POST kprofiles/select {ams_id, tray_id, cali_idx, filament_id, nozzle_diameter="0.4"}` -> 200 `{ok}` (`cali_idx=-1` = default K).
- `PUT kprofiles/{setting_id}/note {note}` -> `{setting_id, note}` ; `DELETE kprofiles/{setting_id}/note` -> 204.
- set/delete/select are refused while RUNNING/PAUSE (409 `printing`) and audited (`kprofile_set|kprofile_delete|kprofile_select`); the list cache is invalidated after set/delete.

## Spool routes (`inventory:write` for writes)
- `GET /api/spools/{id}/kprofiles` -> `[{printer_id, extruder, nozzle_diameter, nozzle_type, k_value, n_coef, name, cali_idx, setting_id}]`
- `PUT /api/spools/{id}/kprofiles` body = same list (replaces; unique on printer+extruder+nozzle -> 422 on duplicates, 404 unknown printer)
- `DELETE /api/spools/{id}/kprofiles/{printer_id}?extruder=0&nozzle=0.4` -> 204

## Status
`GET /printers/{id}/status` `trays[]` gains `cali_idx` (int|null), `k_value` (float|null), `tray_info_idx`.

## Behaviour
- Slot assign with device apply (`ams_slot_configure`) chains `extrusion_cali_sel` when the spool has a stored profile for that printer/nozzle.
- Drift fixer: on idle pushes (IDLE/FINISH/FAILED) and right before a queued job is sent, a loaded tray with `cali_idx` -1/missing whose spool has a stored profile is re-selected (10 min debounce per tray, audit `kprofile.reapply`); a tray holding another real profile is never touched.
