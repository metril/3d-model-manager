## Components
- PrintCalendar (History tab `calendar`); day click -> Runs tab with `?date=` (client-side filter: backend has no date filter)
- ArchiveCompareDialog (sm:max-w-5xl) opened from RecentRunsList selection (max 5)
- RunDetailSheet: ArchiveEditor (notes/tags/override/delete), VerdictCard, PhotoGallery (+lightbox, upload), Edit timelapse -> TimelapseEditorDialog (sm:max-w-3xl); toolpathSlot placeholder
- PostPrintConfirmDialog (AppShell): polls recent archives, shows own pending, snooze in sessionStorage
- Settings Storage: ArchivePurgeCard; Settings Printer: ConfirmOutcomeCard
