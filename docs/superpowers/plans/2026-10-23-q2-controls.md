# Q2 plan: command bus v2, printer controls, Developer Mode

Spec: `~/.claude/plans/i-need-you-to-pure-frog.md` (Q2, risk decisions 2 and 3). Backend only; web lands in Q3.

## Bus
- `_publish_command` sends `{command, args, request_id}`; bare-string commands still work.
- `printers/commands.py`: dispatch table (validator + adapter call + guard flags) shared by printerd and the API.
- printerd `handle_command(command, args, request_id)` runs the table, writes `printer:{id}:cmd_result:{rid}` (30 s TTL).
- API (`api/printer_control.py`) polls the key for 3 s: 200 ok, 409 (dev_mode_off, printing, not_printing, cold_extrude, offline), 422 (unsupported, invalid), 202 pending.

## Adapters
- `PrinterAdapter` gets default-`NotImplementedError` controls; `BambuLanAdapter` uses `bambulabs_api` and `_publish_raw` (airduct, clean_print_error, load, probe). `FakePrinterAdapter` records calls.
- Replies reach printerd through the lib's `on_message_handler` tap (`result` key present).

## Developer Mode (`printers/devmode.py`, pure)
- fun bit; else guarded echo probe (IDLE/FINISH, 5 s, full slot record); else lazy from replies or HMS 0500050000010007. `None` is unknown.
- Stored in `PrinterPublicState.dev_mode` and `dev_mode_reason`. API 409s when false, except pause/resume/stop.

## Safety
- gcode: admin only, 1 KB cap, refused while printing. Jog snaps to {1,10,50} and must fit `build_volume_mm`. Extrude needs nozzle >= 170 C. Home, jog, extrude, gcode, calibrate and load/unload are refused while RUNNING/PAUSE, in the API and again in printerd.
- `audit_log` table (revision `b2f7c1a9d4e3` after `a8e2d4c6b1f3`); gcode, jog, extrude and skip-objects write rows.

## Routes
`POST /printers/{id}/control/{temperature|fan|light|speed|home|jog|extrude|gcode|airduct|calibrate|hms/clear|filament}`, `GET /printers/{id}/objects`, `POST /printers/{id}/skip-objects`, `GET /printers/developer-mode-warnings`.

## Deviations
- Relative Z jog uses G91/G0/G90 (the lib's `move_z_axis` is absolute only).
- Jog "clamp" snaps to the nearest allowed step.
