# T1-be: AMS drying (backend) -- API contract

Branch `t1-be-ams-drying` (stacked on `t3-be-printer-ops`). Perms: `printers:control` = per-printer control
access (`require_printer_access("control")`); `settings:write`; presets/read routes need only a session.

## Printer control (command envelope v2, `run_command`)
`POST /printers/{id}/drying/start` body
`{ams_id: 0-3|128-135, temp: 45-85, duration_hours: 1-24, filament?: str="", rotate_tray?: bool=false}`
`POST /printers/{id}/drying/stop` body `{ams_id}`
Responses: `200 {ok:true}` | `202 {status:"pending",request_id}` | errors `{code, detail, ...}`:
`422 invalid` (bad args / unknown AMS unit), `422 unsupported` (model/firmware cannot dry, e.g. A1/A1 mini),
`409 screen_only` (P1P/P1S: screen only), `409 blocked` + `{codes:int[], messages:str[]}` (unit reports `dry_sf_reason`),
`409 printing` (start while printing unless `capabilities.ams_drying_while_printing`), `409 offline`, `409 dev_mode_off`.
Empty `filament` is backfilled from the unit's loaded tray type (fallback `PLA`). Audited (`drying_start`/`drying_stop`).
Wire: `print.ams_filament_drying {ams_id,temp,cooling_temp:20,duration(hours),humidity:0,mode:1,rotate_tray,filament,close_power_conflict:false}`;
stop = same with `temp:0,duration:0,cooling_temp:0,mode:0`.

## State (`GET /printers/{id}/status`)
`ams_units[]` gains: `dry_time_min:int|null`, `dry_status:int|null` (0 off,1 checking,2 drying,3 cooling,4 stopping,5 error),
`dry_sub_status:int|null`, `dry_sf_reason:int[]`, `humidity_index:int|null` (raw 1-5), `dry_target_temp:int|null`,
`dry_filament:str|null`, `dry_started_at:float|null` (epoch s; target fields are adapter-cached, cleared when status returns to 0).
`humidity` stays relative-% (`humidity_raw`), `null` when the unit reports no percentage (index is never converted).
New `capabilities` object on the status response (firmware-aware; same shape as `PrinterOut.capabilities`).
Capabilities gain `drying_screen_only`, `ams_drying_while_printing`; `ams_drying` is now table-driven
(PrinterOut, firmware unknown -> model table only; status -> firmware-gated).

## Settings
`GET/PUT /settings/drying` (PUT: `settings:write`; GET: session). Body/response:
```
{presets: {PLA: {n3f_temp,n3s_temp,n3f_hours,n3s_hours}, ...},   # temps 45-85, hours 1-24; n3f = AMS 2 Pro (ids 0-3), n3s = AMS-HT (128+)
 ams_humidity_good: 40, ams_humidity_fair: 60, per_type_thresholds: {PLA: 50, default: 60}, # 0-100
 ambient_drying_enabled: false, ambient_sustained_min: 30 (1-1440),
 queue_drying_enabled: false, queue_drying_block: false, print_drying_enabled: false}
```
`GET /drying/presets` (session) -> `{presets: {...}}` effective presets (seed table when unset).
Seed: PLA 45/45/12/12, PETG 65/65/12/12, TPU 65/75/12/18, ABS 65/80/12/8, ASA 65/80/12/8, PA 65/85/12/12, PC 65/80/12/8, PVA 65/85/12/18.

## Schedules (`ScheduledDryingOut`)
`{id, printer_id, ams_id, temp, duration_hours, filament, rotate_tray, start_after: iso|null,
 status: pending|waiting|running|done|failed|cancelled, waiting_reason: str|null (ams_power_required|ams_retract_filament|ams_blocked|printer_busy|printer_offline),
 error_code: screen_only|unsupported|did_not_start|blocked|null, started_at, finished_at, source: manual|ambient|queue,
 created_by_user_id, created_at}`
`GET /printers/{id}/drying/schedules?status=` (session, visible printer) -> list (newest first, 7-day retention for terminal rows)
`POST /printers/{id}/drying/schedules` (control) body `{ams_id, temp, duration_hours, filament?, rotate_tray?, start_after?: iso}` -> 201. Capability preflight: 422 `unsupported` / 409 `screen_only` at create.
`DELETE /drying/schedules/{sid}` (control on its printer) -> `ScheduledDryingOut`; pending/waiting -> `cancelled`; 409 otherwise (`running`: use stop).

## Smart plug
`PlugIn`/`PlugOut` gain `auto_off_after_drying: bool=false`: plug powers off when a unit's drying ends, no print is running and no other unit still dries.

## Beat `drying.tick` (60 s)
due schedules -> preflight -> send; `running` -> `done` when dry_status returns to 0 after being active, `failed/did_not_start` if no
activity within 90 s; ambient (sustained humidity >= threshold for `ambient_sustained_min`, idle printer) and queue drying create schedules
(`source` ambient/queue); `queue_drying_block` holds the printer (`hold_reason` `drying`) while a unit is active; notify events
`drying_started|drying_finished|drying_failed`.
