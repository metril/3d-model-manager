# T8a: Apprise provider + per-user email prefs

Spec: Bambuddy parity v3 roadmap, T8a + ruling 12.

## Part 1: Apprise provider (this branch, now)
- Dep `apprise` (in-process, no network at import). Provider `kind="apprise"`, `supports_photo=True`.
- Fields: `urls` (secret, multiline, required; one URL per line, `#` comments and blanks skipped) (no tag field: URLs are added untagged, so a tag filter would match nothing).
- `send`: one `apprise.Apprise()` per URL (invalid -> `ProviderError` "invalid Apprise URL on line N", URL never echoed); `notify` per URL (not batched), TEXT body; photo attached in memory via `AppriseAttachment(AttachMemory(...))` (no temp file); failures -> `ProviderError` listing `scheme://host` only; apprise logger pinned to WARNING.
- `field()` gains `multiline` and `help`; catalog exposes them; web `ChannelModal` renders a `Textarea` for multiline fields, `kindIcon("apprise")` -> Megaphone.
- Tests: `test_notify_apprise.py`, catalog kinds in `test_notify_api.py`, web ChannelModal vitest.
- Live verify: `2026-10-24-t8a-live-verify.md`.

## Part 2: per-user email prefs (done; rebased on T6-be, head d2e7a1c5b903)
- Migration `e5b8c3a91f47_t8a_email_prefs`: `user_email_preferences(id, user_id uq FK cascade, notify_print_start/complete/failed/stopped bool default false, created_by_user_id, created_at)`.
- `GET/PUT /user-notifications/preferences` (session-only, in `VIEWER_ALLOWLIST` for PUT). GET returns defaults when no row plus `smtp_configured`, `has_email`.
- `tasks/notify.deliver_pending` calls `email_job_owner(item)` per drained event: job_started/finished/failed/paused map to start/complete/failed/stopped; owner = `PrintJob.created_by_user_id` via `payload.job_id`; needs SMTP configured, user email, matching pref. Rendered with the catalog templates, sent via `mailer.send`. Independent of channels; exceptions are swallowed (never blocks channel delivery). External jobs (no starter) send nothing.
- Web: `EmailPrefsCard` in the General tab (hidden unless `smtp_configured`; hint when no email), `useEmailPrefs`/`useUpdateEmailPrefs`, i18n `emailPrefs.*`.
- Tests: `test_email_prefs.py`, `test_migrations_t8a.py`, `EmailPrefsCard.test.tsx`.
