# Q6 Notifications - phase plan

Spec: `docs/superpowers/specs/2026-10-23-bambuddy-parity-v2-design.md` (Q6).

## Data (alembic `c6a1f4d8b2e7`, down `b2f7c1a9d4e3`; re-chain at merge)
- `notification_channels(kind, name, config_enc, enabled, events text[], quiet_hours jsonb, digest_cron, attach_photo, created_by_user_id)`
- `notification_templates(event unique, title_tpl, body_tpl)`; `notification_log(channel_id SET NULL, event, printer_id, status, error, payload, sent_at)`
- Log status: `sent | failed | queued (awaiting digest) | digested | quiet`.

## Backend
- `services/notify/`: `base.py` (Provider protocol, `Message`, `ProviderError`), one module per provider
  (ntfy, pushover, telegram, discord, webhook, email/smtplib, callmebot, bark, homeassistant via
  `HaClient.call_service`). Sync providers with injectable `httpx.Client`. Each declares `fields`
  (drives the UI form) and `supports_photo`.
- Config JSON is Fernet-encrypted (`app.crypto`); secret fields read back as `********`, and sending
  the mask back on PATCH keeps the stored value.
- `templates.py`: `SandboxedEnvironment` + `StrictUndefined`, no autoescape; any error falls back to the event default.
- `events.py`: `emit()` rpush to Redis `notify:queue` (2 s socket timeout, swallows errors); `emit_bg()` on a daemon thread.
- Producers: printerd `_transition_active_job` (job_started/finished/failed/paused), `_notify_changes`
  (new HMS codes vs previous report, dev mode True->False), archive (filament_low on crossing the
  threshold), queue API (queue_item_added, review_requested). HMS text via lazy `app.services.hms` import.
- Celery `tasks/notify.py`: `deliver_pending` (beat 10 s; drains list, fans out to enabled subscribed
  channels), `send_one` (quiet hours -> `quiet`; digest channel -> `queued`; else send with photo;
  3 retries, backoff 5/30/120 s; final outcome logged), `digest` (beat 60 s; due per channel cron, UTC,
  last run in Redis).
- Photo: kept job frame, else live frame (`camera_state`), for telegram/discord/pushover/ntfy/email.
- Routes (`settings:write`): `/notifications/channels` CRUD + `/{id}/test`, `/templates` CRUD +
  `/defaults` + `/preview`, `/log`. `GET /notifications/events` (catalog + provider field specs): session only.
