# T5-be: spool housekeeping (backend) - API contract

Reads: any session. Writes: `inventory:write` (catalog reset: `admin`). All under `/api`.
Spool `location` text column is replaced by `location_id`; responses keep a read-only `location` (name).

## Spools
- `SpoolCreate/Update`: `location_id: int|null` replaces `location`.
- `SpoolOut`: + `location_id`, `location` (read-only name). `SpoolDetailOut`: + `suppliers: SpoolSupplier[]`.
- `SpoolSupplier = {supplier_id, supplier_name, article_number, quoted_price_per_kg, is_purchase_source}`
- `PUT /spools/{spool_id}/suppliers` body = bare array of `{supplier_id, article_number?, quoted_price_per_kg?, is_purchase_source?}` (replace-all; <=1 purchase source; 400 duplicates; 404 unknown supplier) -> `SpoolSupplier[]`
- `POST /spools/bulk-update {ids:int[], update:{material_type?,brand?,color_hex?,color_name?,label_weight_g?,empty_weight_g?,weight_used_g?,cost_per_kg?,low_stock_g?,location_id?,archived?}}` -> `{results:[{id,ok,error?}], not_found:int[]}`
- `POST /spools/bulk-delete|bulk-archive|bulk-restore {ids}` -> same shape (delete refuses spools with usage history / not owner: `ok:false,error`)
- `GET /spools/export.csv[?archived=bool&ids=1,2]` -> text/csv attachment `spools.csv`
- CSV columns: `id,material,brand,color_name,rgba,label_weight,weight_used,remaining,cost_per_kg,empty_weight,low_stock_g,last_used,storage_location,tray_uuid,spoolman_id,suppliers,purchase_supplier` (upstream names; `remaining` export-only; unknown columns ignored with a warning; `suppliers` is `"; "`-joined names)
- `POST /spools/import?dry_run=true` multipart `file` -> `{token: str|null, rows:[{line,action:"create"|"update"|"error"|"skipped",spool_id?,material?,brand?,color_name?,errors:[str],warnings:[str]}], summary:{create,update,error,skipped}, warnings:[str]}`. `dry_run=false` applies immediately and returns the commit result.
- `POST /spools/import/commit {token}` -> `{created,updated,errors}`; expired/unknown token -> 410. Token = Redis key, TTL 15 min.
- Matching existing spools: `id`, then `tray_uuid`, then `spoolman_id`. Unknown suppliers: warning, dropped. Unknown `storage_location` names are created on commit (warning in dry run).
- `POST /spools/labels {ids, template:"tight"|"roomy", page:"a4"|"letter"|"roll_62mm", format:"pdf"|"png"}` -> `application/pdf`, `image/png` (one page) or `application/zip` of PNGs. `POST /spools/labels/preview {ids, template, page}` -> `image/png` (first page). QR = `{public_url}/inventory/spools?spool={id}`.

## Suppliers `/suppliers`
`GET` list, `POST`, `PATCH /{supplier_id}`, `DELETE /{supplier_id}` (204).
`Supplier = {id,name,website,customer_number,note,created_at,spool_count}`; body `{name, website?, customer_number?, note?}`. Duplicate name (case-insens.) -> 409.

## Storage locations `/storage-locations`
`GET` list, `POST {name, identifier?}`, `PATCH /{location_id}`, `DELETE /{location_id}` (204; spools keep `location_id=null`).
`Location = {id,name,identifier,created_at,spool_count,sensors:Sensor[]}`. Duplicate -> 409.
- `Sensor = {id,location_id,name,entity_id,kind,device_class,unit,alert_above,alert_below,notify_on_alert,show_on_card,sort_order,last_state,last_changed_at,alerting}`
- `GET|POST /storage-locations/{location_id}/sensors`; `PATCH|DELETE /storage-locations/sensors/{sensor_id}`
- `GET /storage-locations/sensors/entities[?q=]` -> `[{entity_id,friendly_name,state,unit,device_class}]` (503 if HA unconfigured/unreachable)
- `GET /storage-locations/{location_id}/readings` -> `[{sensor_id,name,kind,entity_id,state,unit,last_changed_at,alerting}]`
- Beat `location_sensors.poll` (120 s): updates readings, emits notify `location_sensor_alert` once per transition into alerting.

## Colour catalog `/color-catalog`
`Entry = {id,manufacturer,color_name,hex,material,is_default,extra_colors,effect_type}`
`GET ?manufacturer=&material=&q=`, `POST`, `PATCH|DELETE /{entry_id}`, `GET /lookup?manufacturer=&name=[&material=]` (404 if none), `GET /nearest?hex=[&manufacturer=]` (entry + `delta_e`), `GET /search?q=` (<=50), `GET /by-material/{material}`, `POST /color-catalog/reset` (admin) -> `{restored}`.
