# Q8c: stats widget dashboard, history modals, i18n

Web only. Spec: Bambuddy parity v2, Q8. Backend (Q8b) provides `GET /stats/dashboard?days=`,
`/printers/{id}/sensors`, `/printers/{id}/ams-history`.

## Stats page (`/stats`, Print group after History)
- `api/stats.ts` `useStatsDashboard(days)`; one payload feeds all widgets.
- `lib/statsLayout.ts`: pure `reorder`/`cycleSize`/`normalize` + per-user localStorage
  (`tdmm.stats.layout.<userId>`); no per-user preferences API exists server-side.
- `components/stats/StatsGrid.tsx`: `@dnd-kit/core` + `sortable` (pointer + keyboard sensors);
  resize = size button cycling 1/2/3 columns (keyboard accessible).
- Widgets (`widgets.tsx`, `registry.ts`): quick stats, success rate, time accuracy, failure
  analysis, activity heatmap (7x24 SVG), records, per-printer table, filament trends.
- Charts are inline SVG; `LineChart` has recessive grid, 2px lines, legend, crosshair tooltip,
  sr-only data table. Categorical colors `--viz-1..7` (dataviz reference palette, light/dark).

## History modals (`components/print/modals/`)
- `HeaterHistoryModal` (nozzle/bed/chamber; chamber omitted if never reported) and
  `AmsHistoryModal` (humidity + temp charts per unit, never dual-axis). Range 1h/6h/24h/7d.
- Buttons live on `PrinterDetailPage` until Q3 wires them into the card; `units` prop is
  `[0]` there (web types do not yet expose AMS unit ids).

## i18n
- `i18next` + `react-i18next` + browser language detector (localStorage `tdmm.lang` first).
- `src/i18n/{index.ts,locales/en.json}`; initialised in `main.tsx` and vitest setup.
- Wrapped: sidebar, topbar, nav items (`useNavLabel` -> `nav.<label>`), Settings page tabs/
  heading, Appearance card (+ language select, contribute note), stats page.
  `components/print/*` and `PrinterCard` untouched (Q3).
- `scripts/i18n-check.mjs` (`npm run i18n:check`): literal `t("key")` / `i18nKey=` usages must
  exist in en.json; other locale files must contain every en key. `npm test` runs it first, so
  the existing web CI job enforces it without workflow edits.
