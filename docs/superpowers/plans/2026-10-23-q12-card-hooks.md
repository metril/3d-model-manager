# Q12 card hooks (final Bambuddy parity v2 phase)

Goal: the dashboard cards get the same wiring the detail page has, plus the last status fields.

## Backend (additive, no migration)
- `PrinterPublicState` / `PrinterStatusOut`: `tray_now` (AMS report `tray_now`; 254 external, 255 none), `door_open` (X1 `home_flag` bit 23, other door models the hex `stat` field; only when `capabilities.door`).
- `ActiveJobOut.thumbnail_url`: `/api/blobs/<hash>/plates/<plate>/thumb` when the job's file is a stored 3MF, else null (`printer_overview._plate_thumb_url`).
- `_snapshot` fills both; A1 Mini fixture gains `tray_now`/`home_flag`.
- Tests: `test_bambu_adapter.py`, `test_printer_status_api.py`, `test_printer_overview_api.py`, `test_perm_sweep.py`.

## Web
- `usePrinterCardExtras(printer, status, {canPrint, canAdmin})` -> `{badgeExtra, footerExtra, onInfo, onDiagnose, onHms, modals}`; footer = CameraSplitButton, PlugRow, Firmware, history buttons.
- `ManagedPrinterCard` per-card wrapper (hook owner) used by `PrintDashboardPage` and `PrinterDetailPage`; the TODO comments go away. S (compact) card shows `badgeExtra` only.
- `CardFooter` drops its placeholder Camera link (the split button replaces it).
- Card: `FilamentsSection` loaded marker from `tray_now`; `BadgeRow` door open/closed chip; `StatusSection` thumbnail from `active_job.thumbnail_url`.
- Mapping pill: `ActiveJobOut`/`PrintJobOut` do not expose an AMS mapping (`tray_snapshot` is usage bookkeeping, not slot mapping), so the pill stays hidden.
- i18n: `card.*` / `dash.*` keys for the card sections, `PrinterCard`, `StatusSummaryBar`, `BulkPrinterToolbar`, `DevModeBanner`. Printer names/user data are never translated.

## Verification
`npm run build`, vitest (print components, pages, shell), `npm run i18n:check`, oxlint; targeted pytest + ruff check/format.
