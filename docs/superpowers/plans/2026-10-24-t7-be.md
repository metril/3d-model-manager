# T7-be: archive extras (backend) - API contract

All paths under `/api`. Session auth unless noted. "visible" = archive's printer in `visible_printer_ids(ctx)` (else 404).
"writer" = admin, OR job owner (`print_jobs.created_by_user_id == me`), OR `printers:print` + per-printer print ACL.

## ArchiveOut additions (list + detail)
`result` = effective (`result_override or recorded_result`); `recorded_result`; `result_override|null`; `notes|null`;
`tags: string[]`; `confirm_requested: bool`; `confirm_expires_at|null`; `user_verdict: "good"|"bad"|null`;
`user_verdict_source: "dialog"|"link"|"plate_clear"|"card"|"api"|null`; `verdict_at|null`; `verdict_by_user_id|null`;
`photos: [{filename, kind: "photo"|"timelapse", uploaded_by|null, at}]`. `GET /archives?result=` filters on effective result.

## Edit / delete
- `PATCH /archives/{id}` body `{notes?: str|null, tags?: str[], result_override?: ArchiveResult|null}` (writer) -> ArchiveOut. AuditLog `archive.result_override` on change. Tags trimmed/deduped, max 20 x 40 chars.
- `DELETE /archives/{id}` (admin) -> 204. Deletes archive row + unreferenced blobs; `print_jobs` kept. AuditLog `archive.delete`.

## Compare
`GET /archives/compare?ids=1,2,3` (2-5 distinct ids else 422; any not visible -> 404) ->
`{archives:[ArchiveOut], settings_diff:[{key, values:{"<id>": any}}], filament:{"<id>": est_filament}, time:{"<id>":{estimated_s|null, actual_s|null}}, correlation:[{key, value, success_rate, n}]}`.
`settings_diff` = only differing top-level `slicer_meta` keys. `correlation` = for each differing key/value across ALL visible archives with the same model (or the compared set if no model), success rate (effective result completed) and n.

## Purge (settings group + routes)
- `GET/PUT /settings/archive_purge` (`settings:write`) `{enabled:false, older_than_days:365 (1-3650), keep_failed:false, keep_with_verdict:true}`.
- `POST /archives/purge/preview` (admin) -> `{count, bytes}`; `POST /archives/purge/run` (admin, AuditLog `archive.purge`) -> `{deleted, bytes}`.
- `GET /archives/purge/stats` (session) -> `{last_run_at|null, last_deleted, last_bytes, next_run: "03:30 daily"|null}`.
- Beat `archive.purge` 03:30 when enabled. Never deletes print_jobs/ledger; skips `confirm_requested and user_verdict is null`, failed (keep_failed), with verdict (keep_with_verdict).

## Calendar
`GET /archives/calendar?from=YYYY-MM-DD&to=YYYY-MM-DD` (to-from <= 400 days else 422) -> `[{date, count, ok, failed, hours}]` (UTC day of `created_at`; ok = effective completed; failed = effective failed/canceled/stopped... only `failed`).

## Outcome confirm
- `GET/PUT /settings/confirm` (`settings:write`) `{enabled:false, external_prints:false, default_outcome: null|"good"|"bad", default_after_h:24 (1-720), default_good_on_plate_clear:false}`.
- Notify event `print_confirm_request` payload `{subtask_name, archive_id, job_id, printer_name, good_url, bad_url}`.
- PUBLIC `GET /archives/confirm/{token}/{verdict}` -> HTML prompt (no state change; `?tap=1` auto-POSTs via inline script); PUBLIC `POST /archives/confirm/{token}/{verdict}` -> HTML result page, records verdict (source `link`). 404 unknown token/verdict; 410 used/expired; 429 over 30/min/IP.
- `POST /archives/{id}/verdict` body `{verdict:"good"|"bad", source:"dialog"|"card"|"api"}` (writer) -> ArchiveOut.
- `bad` sets `result_override=failed` if recorded result differs; `good` clears a failed override only if a prior `bad` verdict set it.
- Beat `archive.confirm_defaults` hourly; `archive_confirm.on_plate_cleared(printer_id, user_id)` subscribed to T3 `hooks` (guarded import).

## Timelapse editor (writer + `printers:print`)
- `GET /archives/{id}/timelapse/info` -> `{duration_s, fps, width, height, bytes}`; 404 no timelapse.
- `GET /archives/{id}/timelapse/thumbnails?n=12` (1-24) -> `{frames: ["data:image/jpeg;base64,..."]}` (Redis cache 1 h).
- `POST /archives/{id}/timelapse/process` form `trim_start` (s, >=0), `trim_end` (s, optional), `speed` (0.25-4.0), `save_mode` `replace|new` -> 202 `{job_id}` (Celery `app.tasks.media.timelapse_edit`).
- `GET /archives/{id}/timelapse/jobs/{job_id}` -> `{state: "pending"|"running"|"done"|"error", error|null, filename|null}`. `new` appends `{kind:"timelapse"}` to photos (stream via photos route); `replace` overwrites `timelapse_blob`.

## Photos (writer)
- `POST /archives/{id}/photos` multipart `file` (jpeg/png/webp, <=15 MB, re-encoded, EXIF stripped, max 4096 px) -> photo item.
- `GET /archives/{id}/photos` -> list; `GET /archives/{id}/photos/{filename}` stream; `DELETE /archives/{id}/photos/{filename}` -> 204.
