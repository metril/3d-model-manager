# T3-be: printer ops backend

All routes require `printers:control` unless noted. Mutations write an AuditLog row.

## API contract
- `POST /printers/{id}/clear-plate` -> `{awaiting_plate_clear:false}`; 400 `not_awaiting` when flag false and gcode_state not FINISH/FAILED. Fires `hooks.plate_cleared(printer_id, user_id)`.
- `PrinterOut.awaiting_plate_clear: bool`; status payload carries it too.
- `GET/PUT /settings/queue` (`settings:write` for PUT) `{require_plate_clear: bool=false}`. When on, dispatcher treats a printer with the flag as ineligible, reason `awaiting_plate_clear`.
- `POST /printers/{id}/control/xcam {module, enable, sensitivity: low|medium|high|never_halt}`
- `POST /printers/{id}/control/print-option {option: auto_recovery|auto_switch_filament, value: bool}`
- State: `PrinterPublicState.print_options: dict` (`xcam` modules `{module:{enable,sensitivity}}`, `auto_recovery`, `auto_switch_filament`). Capability `xcam_modules: list[str]`.
- `POST /printers/{id}/slots/{unit}/{slot}` gains `tray_info_idx, tray_type, sub_brand, color (RRGGBB[AA]), nozzle_min, nozzle_max, apply_device=true`. Device applies only if printer state exists.
- `DELETE /printers/{id}/slots/{unit}/{slot}/device` -> reset slot on device.
- `PUT /printers/{id}/ams/{ams_id}/label {label<=100}`, `DELETE ...` ; `ams_units[].label` in status.
- SD: `GET /printers/{id}/files?path=/`, `GET .../files/download?path=`, `DELETE .../files?path=`, `GET .../files/storage`, `POST .../files/print {path, plate?, use_ams=true}` (.3mf/.gcode.3mf only).
- Capabilities added: `xcam_modules`, `sd_browser`, `sd_print`.
- Migration `t3_printer_ops`: `printers.awaiting_plate_clear`, table `ams_labels`.
